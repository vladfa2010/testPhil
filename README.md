# SCREENPLAY — B2B-лендинг стриминговой платформы

Документация по технологиям, вёрстке, дизайн-системе и функциям. Версия мокапа v1, 2026-11-11.

---

## 1. Обзор

Одностраничный лендинг для B2B-продажи рекламы и спонсорства на стриминговой платформе (фильмы, сериалы, шоу). Целевая аудитория — бренды и рекламодатели. Задача лендинга — привести посетителя к заявке на медиаплан.

Структура страницы (7 смысловых блоков):

1. Hero — оффер и главный CTA
2. Бегущая строка — перечень форматов размещения
3. Манифест — боли рекламодателя и позиционирование
4. Форматы размещения — 5 механик
5. Премьерные окна — полноэкранная панель
6. Метрики отчётности — 4 принципа измерения
7. Пакеты сотрудничества — 3 уровня + форма заявки

## 2. Технологии

| Слой | Решение | Почему |
|---|---|---|
| Разметка | HTML5, семантические теги (`header`, `section`, `footer`, `nav`, `form`) | доступность и SEO-база без сборки |
| Стили | Чистый CSS3, каскадные custom properties (`:root`) | нет зависимостей и сборки, токены в одном месте |
| Скрипты | Ванильный JavaScript (IIFE, strict mode), ~90 строк | интерактив без фреймворков |
| Шрифты | Google Fonts: Archivo (в Var-ось wdth 62–125, wght 300–800) + JetBrains Mono | одна переменная гарнитура для дисплея и текста, моноширинный для микротекста |
| Изображения | 3 сгенерированных кинематографичных кадра, JPEG ~100–290 КБ, `object-fit: cover` | полный контроль палитры, вес страницы < 600 КБ |
| Сборка | Не требуется — статический файл `index.html` + папка `assets/` | деплой любым статическим хостингом |

Зависимостей, npm и CDN-библиотек нет — страница работает offline (кроме подгрузки шрифтов).

## 3. Вёрстка

### Сетка и отступы
- Блочно-модульная вёрстка: каждая секция — независимый блок со своим вертикальным ритмом.
- Боковые поля страницы — переменная `--pad: clamp(20px, 4vw, 64px)`: плавный рост отступа от мобильного к десктопу.
- Внутренние сетки — CSS Grid (`manifesto-grid` 1.5fr/1fr, `frow-in` 80px/1.1fr/1.4fr/auto, `mgrid` 4 колонки, `pgrid` 3 колонки через `gap:1px` на фоне линии).
- Межколонники и разделители — 1px-линии `rgba(245,242,234,.14)`, без карточных теней и радиусов (радиус только 2px у кнопок).

### Адаптив
- Breakpoints: 900px (планшет/мобайл) и 560px (телефон).
- Hero-метаданные: с 560px переходят в одну колонку.
- Сетки метрик: 4 → 2 → 1 колонка; сетка форматов: 4 колонки → «номер + заголовок / описание».
- Вращающаяся печать и кастомный курсор скрыты на мобильных (`max-width:900px`, `hover:none`).
- Горизонтального скролла нет на всех ширинах (проверено на 390px).

### Производительность
- Анимации только на `transform` и `opacity`, фильтр `blur` — только на старте появления (не в hover-циклах).
- `will-change` не используется массово; `backface-visibility` не требуется — нет drag-слайдеров.
- Критический CSS инлайн в `<head>`, скрипт в конце `<body>` без `async`-блокировки рендера.

## 4. Дизайн-система

### Палитра (токены в `:root`)
| Токен | Значение | Роль |
|---|---|---|
| `--bg` | `#0B0B0D` | основной фон, тёплый near-black (не чистый #000) |
| `--panel` | `#101014` | фон секции «Форматы» |
| `--ink` | `#F5F2EA` | основной текст, тёплый off-white |
| `--muted` | `rgba(245,242,234,.55)` | вторичный текст |
| `--faint` | `rgba(245,242,234,.32)` | метки, подписи |
| `--line` | `rgba(245,242,234,.14)` | разделители и рамки |
| `--gold` | `#C9A05C` | акцент: CTA, номера, активные состояния |
| `--gold-soft` | `rgba(201,160,92,.55)` | полупрозрачный акцент |

Плоская кинематографичная подача: без градиентов в UI (градиенты — только тёмные оверлеи поверх фотографий для читаемости текста). Акцент занимает < 10% площади страницы.

### Типографика
- Дисплей: Archivo `font-stretch:75%` (конденсированная ось), wght 700–800, `text-transform:uppercase`, `line-height:.92`, размеры через `clamp` (hero до `8.4vw`).
- Текст: Archivo 400/500, 17px/1.6, максимальная мерa ~65–75 знаков.
- Микротекст (кикеры, номера, кнопки): JetBrains Mono 11–13px, `letter-spacing:.14em`, uppercase.
- Иерархия заголовков: H1 (hero) → H2 секций (`clamp(34–76px)`) → H3 карточек.

### Детали-«подписи»
- **Плёночное зерно** — фиксированный оверлей SVG `feTurbulence`, шаговая анимация 0.9s steps(3), opacity .07: кадр «дышит» как плёнка.
- **Вращающаяся печать** — SVG `textPath` по кругу («SCREENPLAY · PREMIUM VIDEO · B2B»), вращение 14s linear infinite, в hero справа сверху.
- **Пронумерованная навигация** — 01–04 с золотым номером и underline-линией, растущей при hover.
- **Золотая бегущая строка** — прерывает ритм страницы между hero и манифестом, анимация `translateX(-50%)` 26s linear, контент продублирован скриптом для бесшовности.
- **Кнопки** — контурные, 1px; заливка золотом появляется через `clip-path: inset(50% 50%) → inset(0 0)` за 0.4s; стрелка уезжает вправо на 6px.

### Моушен
- Появление блоков: `opacity 0 → 1`, `blur 14px → 0`, `translateY 28px → 0`, изинг `cubic-bezier(.8,0,.2,1)`, 1.1–1.2s — эффект «проявки кадра».
- Каскадные задержки: `.rv-d1…d4` — 0.12s шаг.
- Hero-фон: медленный zoom `scale(1.04→1)` за 14s.
- Ховеры < 300–500ms, только transform/opacity/clip-path; `prefers-reduced-motion` отключает зерно, бегущую строку, появления и плавный скролл.
- Кастомный курсор (десктоп): точка 8px следует за мышью точно, кольцо 34px догоняет с lerp 0.14; на интерактивных элементах кольцо растёт до 56px с золотой обводкой.

## 5. Функции и интерактив

| Функция | Реализация | Поведение |
|---|---|---|
| Липкая шапка | `position:fixed` + класс `.solid` по скроллу | после 40px появляются blur-фон `rgba(11,11,13,.82)`, нижняя линия |
| Плавный скролл к якорям | `scroll-behavior:smooth` + якоря `#formats #premier #metrics #contact` | все ссылки ведут на существующие секции |
| Появление при скролле | `IntersectionObserver` (threshold .12, rootMargin −6%) + класс `.in` | элемент один раз проявляется и отписывается; страховочный таймаут 700ms форсит `.in` для элементов уже в вьюпорте (защита от сбоев IO) |
| Кастомный курсор | mousemove + rAF-цикл, класс `cursor-hover` на `a, button, input` | скрыт на тач-устройствах и < 900px |
| Форма заявки | `submit` перехватывается, валидация: имя, компания, email (regex) | пустое/невалидное поле — красное подчёркивание 1.6s; успех — кнопка скрывается, показывается блок «Заявка принята» |
| Бесшовная бегущая строка | скрипт дублирует контент трека | цикл без разрыва |
| Строки форматов | hover: сдвиг контента вправо на 18px, стрелка → уезжает на 8px и золотится | чистый CSS |

Нет мёртвых элементов: каждая кнопка и ссылка имеет действие (якорь, скролл, mailto или обработчик формы).

## 6. Доступность и качество

- Контраст: основной текст на фоне ~14:1, вторичный ~5.6:1, золотый акцент на тёмном ~7:1 — выше порогов WCAG AA.
- `:focus-visible` — золотая обводка 2px с отступом 3px на всех интерактивах.
- Семантика: у изображений-подложек пустой `alt` + `aria-hidden` где декоративны; форма — `label`+`input`, блок успеха — `role="status"`.
- Проверено: десктоп 1440px и мобайл 390px скриншотами, все состояния формы, отсутствие горизонтального скролла, отсутствие 404 на ассетах.
